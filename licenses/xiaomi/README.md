# Xiaomi protocol references

MiCast cloud implementation was developed with reference to the MiService protocol implementations at https://github.com/Yonsm/MiService and https://github.com/yihong0618/MiService (miservice-fork 2.9.3). Their MIT license notices are retained here. MiCast owns credential lifecycle, transport errors, caching and model routing; no runtime import of either package remains.
