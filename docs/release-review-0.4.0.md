# 0.4.0 发布预检

对比基线：`v0.3.4`。范围包括当前工作区的已修改文件和未跟踪的新文件。

## Review 发现与处理

- **P1，已修复：发布版本号不一致。** 应用及飞牛清单为 0.3.5，Python 项目及 Windows 安装器为 0.3.4。直接打 0.4.0 标签会触发发布校验失败。四处已统一为 0.4.0。
- **P2，已修复：DLNA 定位失败后原缓存 URL 失效。** `DlnaDelivery.seek()` 回滚时再次生成缓存令牌，原音箱继续请求旧 URL 会得到 404。回滚现恢复原令牌，并新增失败定位测试；成功定位和被新歌曲替换的逻辑仍保留令牌撤销行为。
- **发布说明已调整。** Windows 和飞牛 Release 使用 `docs/release-notes-0.4.0.md`，关闭自动生成提交记录；飞牛 manifest 使用相同的用户可感知条目。
