版本与更新日期：2026-10-16

## 1. 适用范围与项目关系

MiCast 是由 DyMode 维护的第三方音频投送工具，用于在您授权的设备之间接收、转发和处理音频。本协议适用于项目提供的应用及相关使用功能。MiCast 并非小米、Apple 或飞牛的官方产品，也不代表获得这些厂商的认证或担保；相关名称和商标归各自权利人所有。

安装前请阅读本协议与《MiCast 隐私政策》。不同意时请取消安装；安装向导中的同意仅适用于所展示的版本，不代表同意以后新增的数据用途。

## 2. 使用权限与内容责任

请仅连接您有权使用的账号、音箱、网络和音频来源，并遵守适用法律及第三方服务规则。您应自行确认所播放内容的使用权限，不得借助本应用侵犯他人权益、绕过付费或访问限制，或干扰他人设备。MiCast 不提供音乐内容授权。

请妥善保管登录凭据和管理访问权限。多人共用 NAS 时，能够访问应用、共享目录或系统管理员权限的人可能接触设备信息、播放状态和日志。

## 3. 第三方服务与兼容性

部分音箱控制和带屏歌曲匹配功能需要您主动连接小米账号，并访问小米及相关内容服务。登录、查询、控制和内容展示受第三方服务条款、接口、曲库和设备固件影响。第三方可能调整或停止接口。

AirPlay、AirPlay 2、DLNA 的可用性受部署架构、网络和设备支持情况影响；多音箱同步、音质、封面和歌词效果无法对所有设备及曲目作出保证。带屏显示依赖小米曲库匹配，并非向音箱直接推送任意歌词。

## 4. 安全使用与配置维护

建议在可信局域网使用，并按需要启用管理访问保护。管理登录不能替代投送协议自身的安全措施；请谨慎配置公网映射、防火墙和共享权限。开始播放及调整均衡器、增益、测试音前，请先降低音量，保护听力和设备。

升级、迁移及卸载前请按需要备份配置，并核对卸载的数据保留选项。停止服务会中断投送，保留配置不等于保留有效登录；迁移后可能需要重新连接账号。共享目录、浏览器偏好和您另行保存或发送的文件需要单独处理，详见隐私政策。
