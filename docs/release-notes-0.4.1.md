# MiCast 0.4.1 🎵

本次更新集中改善首次引导、移动端布局和飞牛安装体验，并更新全平台品牌图标。

## 引导与界面

- 移动端首次引导的步骤条固定在顶部，与内容间距缩小；米家二维码展开后可正常滚动到底部操作区。
- “简化视觉效果”改为默认开启，可在引导最后一步直接关闭，之后仍可在设置中调整。
- 引导页固定使用默认明亮主题，不再被浏览器遗留的深色偏好影响。
- DLNA 播放入口使用官方图标，与米家入口保持一致的尺寸和位置。
- 未登录米家或未开启网络发现时，播放入口显示“未连接”并弱化不可用状态。
- 优化桌面侧栏播放器与音量行布局，窄侧栏下的对齐和滚动更稳定。

## 图标与安装

- 全平台品牌图标更新为超椭圆外轮廓，补齐飞牛 32–512 多尺寸图标和 Windows 安装向导图。
- 飞牛安装/升级不再插入自定义确认页，直接使用包内官方《用户协议》《隐私政策》；完整条款仍可在“设置 → 关于与支持”查看。
