# MiCast 0.4.0 🎵

- 【修复】DLNA 投送后无法播放、部分音源起播失败的问题，改善暂停、继续播放和进度拖动体验。
- 【修复】AirPlay 2 开启调音台、均衡器或左右声道分配后无法播放的问题。
- 【修复】部分播放场景下，歌曲封面、歌词匹配及切歌后信息更新异常的问题。
- 【优化】调整桌面与手机界面的间距、按钮和布局，让操作更紧凑、清晰。
- 【新增】“简化视觉效果”开关，可关闭动画、玻璃模糊和动态高光，减轻界面运行负担。
- 【优化】飞牛应用启动与启停体验，减少启动等待和重复启用引发的异常。
- 【优化】飞牛安装流程，自动分配可用端口；升级保留已有配置，卸载时可选择数据保留方式。
- 【新增】用户协议、隐私政策、联系支持与支持开发入口。
