# 音量控制

## 三种音量

- **独立音量**：调整本次投放的数字音量，不改音箱自身音量。
- **音箱音量**：设备提供的 0–100 档位，不代表实际声压或功率百分比。
- **响度平衡**：组合内各声道的 dB 补偿，不改变设备音量，只做响度对齐。正增益可能失真，优先调低较响的一侧。

## 两种控制方式

在全局设置里选择，模式在下一次会话开始（或 DLNA 设置新媒体）时确定，进行中的会话保持原模式。

- **独立音量**：MiCast 自己控制数字音量，音箱音量不动。
- **音量联动**：MiCast 不做数字衰减，把接收到的音量值下发给本次会话的目标音箱，避免双重衰减。没有收到发送端音量时不猜测、不设置。

## 各入口的行为

- **AirPlay / AirPlay 2**：底部控制条与页面上的音箱音量控制的是音箱；音箱音量变化由 MiCast 下发。AirPlay 2 接收端把音量变化回传给 MiCast，自身不再重复衰减；新建管线在收到有效音量前保持静音。
- **DLNA 独立模式**：通过实时转码调整声音，音量变化作用于后续音频；音箱自身缓冲会带来响应延迟。
- **网络 AirPlay 输出**：独立模式对 PCM 做数字音量；联动模式使用该设备的音量命令。这类设备没有通用的音量读取接口，因此只在已连接时支持设定，不参与同步增减，也不用上次发送值猜测当前值。
- **网络 DLNA 输出**：通过设备的标准音量服务设置与读取；设备不提供该服务时明确报告不支持。读取失败时报告失败，不用缓存值代替。

## 页面上的控制范围

- **音箱行**：只控制这一台。
- **全部音箱**：控制当前页面列出的在线音箱。
- **组合音量**：控制该组合包含的米家音箱与网络音箱；逐台返回结果，部分失败不影响成功的音箱。
- **底部控制条**：控制当前列出的音箱（音箱音量）。只有一台时直接控制；多台时可选择全部或单台，全部时显示平均值，拖动统一设置。
- **测试音箱音量**：只控制诊断页选定的设备。

**相对调节**先读取每台当前值，再分别增减并限制在 0–100；**统一音量**直接设置同一个值。到达上下限后数值差异不一定保持，数值相同也不等于听感相同。部分失败会明确提示，成功的结果照常写入共享状态。

## 起播音量

独立开关与数值：关闭表示保持原音量；开启时 0 表示静音。在会话开始后应用，音量联动模式下不应用（避免覆盖发送端指令）。保存这个设置本身不会触发播放，也不会立即修改音箱音量。
