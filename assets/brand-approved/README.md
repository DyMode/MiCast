# MiCast 品牌图标

- 矢量母版：`micast.svg`
- 设计预览：`micast-preview.png`（512 × 512，sRGB）
- 比例记录：`proportions.json`
- 背景：陶土红 `#B94B36`，纯色，无渐变。
- 图形：暖白 `#FFF7ED`，两枚错位叠放的音箱，前实后虚。
- 圆角底板占画布 90%，四周透明留白 5%。
- 图形包围盒约占底板宽度 61%、高度 63%。

本目录为唯一的视觉母版。平台导出文件在 `../icons/`，使用 `../export_icons.py` 重新生成；导出脚本生成完整资产包 `../micast-icons.zip`。
不同平台和尺寸采用各自的透明度、线宽和留白适配，保持品牌配色、组合造型和前实后虚关系。正式文件不带版本号后缀。
